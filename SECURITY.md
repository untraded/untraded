# Security policy

Untraded handles Steam credentials (bot accounts), match history authentication codes and personal match data. We take vulnerabilities seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting: *Security → Report a vulnerability* on this repository. We aim to acknowledge reports within 72 hours.

## Scope

- Leaks of secrets (bot credentials, refresh tokens, auth codes, API keys).
- Access control between workspaces.
- Ingestion endpoints (demo uploads, webhooks).

## Supported versions

Only the latest release receives fixes during the pre-1.0 period.
